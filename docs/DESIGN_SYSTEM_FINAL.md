# Final product design system

The defining view is a working Attention Map between original source and evidence questions. A compact editorial introduction makes room for that work on the first screen. The journey is Read → Understand → Verify → Plan → Rest → Return.

Warm ivory `#F8F6F0`, deep ink `#17352E`, moss `#658674`, pale sage `#DDE9DE` and restrained amber distinguish evidence, waits and review. Georgia headlines, system sans controls and monospace occurrence annotations require no font download. Source text remains verbatim; icons do not carry the only status information.

Desktop: three principal regions with the widest column reserved for Attention. Tablet: source and map above full-width Intelligence. Phone: map, intelligence, then source, with compact scenario controls and horizontal journey navigation. Every citation can open its exact original occurrence. Long source lists scroll within their pane. Keyboard focus is visible; reduced motion disables arrival/loader animation while real timer state continues.

Ask BenchSloth offers three real captured questions per scenario in public replay. Evidence, ambiguity, raw proposal, routing and measured request time are explicit. Browser-derived handoff facts have a separate provenance label. No static freeform box pretends to provide fresh inference. Source corrections invalidate old answers and preserve timer restrictions.

The original sloth and botanical timer remain signature artwork. Loading displays actual stages and wall time, without fabricated percentages or artificial waiting. Breathing Room is deliberately quiet; Return Handoff records what the browser observed, with a direct path to the next original instruction.

## Inspiration and tools

The Pinterest [Botanical Notebook reference](https://uk.pinterest.com/pin/botanical-notebook--481040803956010894/) and [Notebook Admin Dashboard reference](https://in.pinterest.com/pin/notebook-admin-dashboard-design--7599893098444329/) informed calm page hierarchy and notebook structure. They are references, not copied assets. The user-provided Sensa/Forest/editorial references serve the same role. All shipped cover and architecture graphics are original SVG; product screenshots depict actual app states.

No scientific mechanism figure requires BioRender. No backend migration warrants Base44 or Lovable. The prior Canva concept is supplemental; the shipped cover is original and reproducible. Adding those services solely for a logo would weaken the submission. No integration or additional prize category is claimed.

## Verification scope

Actual Chromium captures cover desktop, laptop,390/320px phones, source/answer navigation, manual corrections, real ten-second timer completion, current handoff and checkpoints. Static subpath, video seeking, relative assets, evidence filters, reviewer export, keyboard and reduced-motion checks are recorded separately. Sampled contrast checks are not a full WCAG audit; browser checks are not human usefulness evidence.
