What the comparison measures

The primary score requires exact answer status and exact evidence IDs. Extra evidence counts against every method. The baseline is BM25 retrieval with section context, a generic attention vocabulary, factual-value checks and v0.5 structural candidate rules. All original source remains visible. The top3 retrieval shortlist contains all required passages for16/16 answerable questions. The v0.5 source-view adapter is explicitly the same retrieval baseline: v0.5 had no native QA interface. This is not a new v0.5 model inference run.

Gemma selects evidence candidates, including no-answer and ambiguity options. Verification checks IDs, verbatim excerpts, schema, earlier targets and explicitly unresolved language. It cannot certify semantic truth. QA is read only and makes no timer offers. Intervals are descriptive; related wording and implementer-visible labels limit generalization. Complete QA workflow means exact status, IDs and question-specific relationship, not physical task completion.

Architecture, boundaries & ownership

Read → retrieve → local Gemma interpretation → evidence checks → human review → source-restricted plan → manually confirmed interval → original-source handoff.
